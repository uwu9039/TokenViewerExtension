# 隐私政策 / Privacy Policy

**生效日期：2026-08-13**

## 中文

TokenViewerExtension（"本扩展"）尊重你的隐私。本政策说明本扩展如何处理你的信息。

### 我们收集什么

- **你主动提供的配置信息**：DeepSeek API Key 与 DeepSeek 官方平台 Token。这些信息仅用于：查询你的 DeepSeek 账户余额、拉取你的 token 用量数据，并在你授权后向 DeepSeek 服务器发起查询。
- **你的 DeepSeek 账户数据**：token 用量、请求次数、消费金额、账户余额等，仅在你配置了对应凭证后拉取并展示给你本人。

### 数据如何存储

- 所有配置（API Key / 平台 Token）仅保存在**你的本机**（%LOCALAPPDATA%\TokenViewerExtension\settings.json），不上传至任何第三方服务器。
- 用量数据直接从 DeepSeek 官方接口实时获取，展示于你的设备上，不经过任何中转服务器。
- 本扩展不包含任何遥测、统计或广告 SDK，不收集你的浏览历史、位置、联系人等个人信息。

### 数据共享

- 我们**不会**出售、出租或与任何第三方共享你的数据。
- 数据仅在你的设备与 DeepSeek（你授权查询的对象）之间传输。

### 安全提示

- API Key 与平台 Token 属于敏感凭证，请勿泄露给他人；卸载扩展或清除本地数据目录后，配置将被删除。
- 平台 Token 有效期为数天，过期后需重新获取。

### 联系我们

如对隐私政策有疑问，请通过 GitHub Issues 联系我们：https://github.com/uwu9039/TokenViewerExtension/issues

## English

TokenViewerExtension (the "Extension") respects your privacy. This policy describes how the Extension handles your information.

### What we collect

- **Configuration you provide**: Your DeepSeek API key and DeepSeek platform token. These are used solely to query your DeepSeek account balance and fetch your token usage data, and only when you have configured them.
- **Your DeepSeek account data**: token usage, request counts, spend, and account balance, fetched and displayed to you only after you configure the corresponding credentials.

### How data is stored

- All configuration (API key / platform token) is stored **locally on your device** (%LOCALAPPDATA%\TokenViewerExtension\settings.json) and is never uploaded to any third-party server.
- Usage data is fetched in real time from DeepSeek's official interfaces and displayed on your device; it does not pass through any relay server.
- The Extension contains no telemetry, analytics, or advertising SDKs, and does not collect browsing history, location, contacts, or other personal information.

### Data sharing

- We do **not** sell, rent, or share your data with any third party.
- Data is transmitted only between your device and DeepSeek (the party you authorize).

### Security notes

- The API key and platform token are sensitive credentials. Do not share them with others. Uninstalling the Extension or clearing its local data directory removes the stored configuration.
- The platform token expires after a few days and must be re-obtained.

### Contact

For questions about this policy, please contact us via GitHub Issues: https://github.com/uwu9039/TokenViewerExtension/issues
